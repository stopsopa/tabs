Events - run javascript when tab becomes visible

Every time tab becomes visible (also the initial one) event vanilla-tabs:change is dispatched on the tab content element and it bubbles, so one listener on document handles all tabs, also those created later. Register it before loading vanilla-tabs.js (when using ?vanilla-tabs-autoenable) if you need to catch initially active tabs too.

Or bind to one particular [data-vanilla-tabs] element. Listener lives on that element, so when element is removed from the page listener is destroyed with it - no cleanup needed. Events from tabs nested inside are ignored.
